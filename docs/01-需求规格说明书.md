# 1. 产品概述

## 1.1 产品定位

Beyond Compare 是一款用于**比较文件和文件夹**的桌面实用程序。它帮助用户查找和协调（reconcile）源代码、文件夹、图像和数据中的差异，即使文件包含在 zip 压缩包内或位于远程服务（如 FTP 站点、云存储）上。它能够同步文件夹并验证备份副本的正确性。

产品核心价值：

1. **专用视图体系**：针对不同类型的文件（文本、表格、十六进制、图片、媒体、注册表、版本资源）与不同的差异调节方法（比较、合并、同步）提供专门的会话视图。
2. **从宏观到微观的无缝衔接**：文件夹结构比较 → 双击进入文件内的单个差异；文件级视图的差异信息回传文件夹会话（颜色覆盖），帮助快速聚焦重要差异。
3. **规则驱动的"重要性"模型**：通过规则（Rules）与文件格式（File Formats）把差异分为"重要"与"不重要"（空白、大小写、注释、行尾、行号等），让用户只看到关心的差异。
4. **会话记忆**：每个比较任务是一个可命名、可保存、可重用的会话（Session）；大量设置按会话而非全局存储，不同任务可以有完全不同的设置。
5. **可自动化**：命令行接口（bcompare / bcomp）、脚本处理器（约 30 个脚本命令）、报告生成（HTML / 纯文本 / 打印机 / XML / 补丁格式）支持无人值守批处理。
6. **统一虚拟文件系统**：本地盘、网络共享、FTP/FTPS/SFTP、WebDAV、Dropbox、OneDrive、Amazon S3、Subversion 仓库、MTP 便携设备、HTTP 页面、压缩包内部、快照文件，全部视为等价的"文件夹/文件"来源。

## 1.2 版本划分：Standard 与 Pro

试用版实际包含 Standard + Pro 全部功能，可在"关于"对话框禁用专业模式以试用 Standard 行为；许可密钥决定永久解锁的版本，Standard 可补差价升级到 Pro。

依据本机帮助文档 `standard_vs_pro.html`（权威清单），Pro 版独有功能为：

| # | Pro 专属功能 | 说明 |
| --- | --- | --- |
| 1 | 三向合并（3-Way Merge） | 比较独立更改与公共祖先以生成新的合并内容，适用于文件夹（Folder Merge）或单个文件（Text Merge 的 center 窗格 + output 窗格） |
| 2 | 文本替换（Text Replacements） | 若一侧文本更改为另一侧的特定值（如左侧 `apple` 对右侧 `orange`），则将其指定为不重要差异 |
| 3 | 文件夹比较对齐覆盖（Alignment Overrides） | 覆盖文件在文件夹比较中的默认按名对齐，例如将一侧 `*.gif` 与另一侧同名 `*.png` 配对比较 |
| 4 | 源代码管理集成（SCC 集成） | 添加用于在 SCC 兼容版本控制系统中签入/签出文件的命令（MSSCCI 提供程序） |
| 5 | SFTP 支持 | 内置安全 FTP 协议（SFTP 与 FTP over SSL），不依赖第三方方案 |
| 6 | 注册表比较 | 比较实时注册表（本地与远程）以及 `.reg` 导出文件 |

Standard 版本身即为全功能比较工具（非精简版）：包含全屏编辑、完整 Unicode 支持、语法高亮、文件夹/文本/表格/十六进制/图片/媒体/版本比较、脚本、报告等。

> 实现含义：复刻时可将"Pro 专属"作为许可开关（特性门控）而非架构差异；架构上所有会话类型统一实现，由许可证状态决定可用性。

# 2. 核心概念模型

## 2.1 术语表（权威定义，源自 glossary.html）

| 术语 | 定义 |
| --- | --- |
| 会话（Session） | 一个比较任务，如比较文件夹或文件。每个会话视图显示在自己的顶层窗口或窗口的选项卡中 |
| 子会话（Child Session） | 从文件夹会话启动的文件会话 |
| 视图（View） | 作为窗口或选项卡显示的打开的会话（或主页视图） |
| 工作区（Workspace） | 所有打开会话的集合，包括窗口和选项卡的大小和位置 |
| 基文件夹（Base Folder） | 文件夹视图任一侧的最顶层文件夹；名称显示在每个比较窗格上方的路径编辑中 |
| 孤立项（Orphan） | 比较中一侧有而另一侧没有的项目 |
| 冲突（Conflict） | 三向合并中，同一部分文本在左右两侧都有（不同）更改时发生 |
| 部分（Section） | 具有差异的连续行范围 |
| 规则（Rules） | 控制比较执行方式的会话设置 |
| 文件格式（File Format） | 表征文件类型的设置集合：视图类型、转换例程、语法、制表位、大小写敏感性、行权重等 |
| 过滤器（Filter） | 限制显示或处理内容的设置；分为文件过滤器与显示过滤器 |
| 重要文本（Important Text） | 对比较很重要的文本（红色显示） |
| 不重要的差异（Unimportant Difference） | 定义为对比较不重要的文本差异（空白、大小写、注释、行号等；蓝色显示） |
| 行尾样式（Line Ending） | 文本文件每行结尾的控制字符模式：Windows CR+LF、Unix LF、旧 Mac CR |
| 空白（Whitespace） | 行首、行尾和单词之间的空格与制表符组合 |
| CRC | 循环冗余校验，文件内容的数值表示；CRC 不同则内容必不同，相同则很可能相同（CRC32） |
| CSV | 逗号分隔值，行列数据文件布局 |
| 快照（Snapshot） | 包含文件夹树信息的自定义 Beyond Compare 文件（.bcss），捕捉某时刻文件夹状态供日后与实时文件夹比较 |
| 缩略图（Thumbnail） | 文件比较窗口左侧（可选）的差异彩色编码摘要面板，每行一像素高 |
| 时间戳（Timestamp） | 文件或文件夹的上次修改时间 |
| 修改时间（Touch） | 将文件的时间戳设置为特定值的操作 |
| 容差（Tolerance） | 表格比较与图片比较中，两个单元格（或像素）可不同但仍视为不重要差异的数量；小于等于容差的差异不重要 |
| 偏斜容差（Skew Tolerance） | 查找匹配部分时算法向前/向后搜索的行数 |
| 配置文件（Profile） | 包含远程服务（FTP、WebDAV、Dropbox、Subversion 等）设置和凭据的命名集合 |
| 正则表达式 | 匹配遵循模式的字符串的公式（PCRE） |
| 规格（Specs） | 文件夹或文件的名称（路径表示法，见 2.5） |
| 插件（Plugin） | 可"插入"程序以获得更多功能的软件附件（如 Total Commander 打包器插件） |

## 2.2 比较 vs 合并 vs 同步

| 模式 | 目标 | 输入 | 输出 |
| --- | --- | --- | --- |
| 比较（Compare） | 查看/分析差异 | 2 个输入（左/右） | 只读或可编辑的并排视图 + 状态回传（文件夹侧） |
| 合并（Merge） | 将两个独立变更集合并为新版本 | 2 或 3 个输入（左/右 + 可选中间祖先）+ 输出目标 | 文本：输出窗格内容；文件夹：输出文件夹树 |
| 同步（Sync） | 通过复制/删除使两侧一致 | 2 个文件夹 | 文件复制/删除操作队列（先预览后执行） |

- **双向比较无法区分"一侧新增"与"另一侧删除"**；三向合并引入公共祖先（中间/center/base）后可以推断：祖先没有而一侧有 = 添加；祖先有而一侧没有 = 删除。
- 同一基文件夹可在三种模式间转换：文件夹比较视图提供"合并基文件夹""同步基文件夹"命令；文本比较视图提供"合并文件"命令。

## 2.3 三向合并模型（3-Way Merge Concepts）

- 输入：左（本地）、右（远端）、中（可选，公共祖先）。
- 状态分类（文本合并）：
  - 未更改（三侧相同）
  - 相同更改（左右做了相同更改 → 不算冲突）
  - 仅左侧更改（青色）
  - 仅右侧更改（洋红色）
  - 左右不同更改（冲突，红色）
- 冲突判定范围可配置：
  - "仅更改不同的行"：冲突限制在每一行在两侧都有更改处；
  - "左侧更改和右侧更改之间用行分隔"：指定应视为冲突的两侧更改之间的最大行数，使彼此接近的更改也标记为冲突供审查。
- 首次加载时：若可自动采用非冲突更改则输出窗格为自动合并结果，否则输出与中间内容一致；每个更改以来源窗格颜色显示。
- 手动编辑输出使该部分变黄；可再次使用"采用"命令还原为某一输入。

## 2.4 规则 vs 文件格式

- **规则（会话设置）**：控制"如何比较"——哪些元素重要、用什么算法对齐、比较哪些文件属性等，按会话存储，作用域可细化（见 FR-SES-006）。
- **文件格式**：控制"如何处理某一类文件"——掩码匹配、视图类型（文本/表格/十六进制/图片/版本/外部）、加载与保存转换（外部转换程序 %s/%t/%o）、语法元素定义（供语法高亮与重要性判定）、制表位、行权重、行独立/列数据标志。
- 两者协作：会话的"重要性"选项卡列出当前文件格式的语法元素复选框（抽象层），文件格式的"语法"选项卡定义元素的具体匹配规则（细节层）。
- 文件格式影响文件夹会话：基于规则的内容比较使用文件格式决定两文件是否"基于规则相同"。

# 3. 按会话类型的详细功能需求

> 编号约定：FR-<域>-<序号>。每个功能点包含：行为描述、触发方式、边界情况（如有）。
> 域代码：DIR=文件夹比较，DMRG=文件夹合并，SYNC=文件夹同步，TXT=文本比较，TMRG=文本合并，TBL=表格比较，HEX=十六进制比较，PIX=图片比较，MED=媒体比较，REG=注册表比较，VER=版本比较，CLIP=剪贴板比较，PATCH=文本补丁，EDIT=文本编辑。

## 3.1 文件夹比较（Folder Compare）

### 3.1.1 功能定位

FR-DIR-001 并排文件夹结构比较
- 行为：以资源管理器风格的变体并排比较两个基文件夹。任一侧可以是本地/网络文件夹、远程服务（FTP 等）、压缩包、快照；所有来源被视作等价的"结构——包含文件的文件夹和子文件夹"。
- 触发：主页视图"文件夹比较"按钮；命令行两个文件夹参数；`-fv="Folder Compare"`；从其他会话"比较父文件夹"。
- 边界：任一基文件夹加载失败时弹出 `TDirLoadErrorDialog`（实测 BCState.xml 中存在该对话框记录）；加载不存在的基文件夹可在命令行/路径编辑回车后提示"创建"。

FR-DIR-002 文件夹状态聚合
- 行为：文件夹本身的时间戳不参与比较；文件夹的比较状态由其内容聚合得出（如"至少包含一个右侧较新的文件"→红色，"两侧各至少一个孤立项"→紫色提示）。未扫描完成时显示为空心图标；自动扫描关闭且未展开时显示黄色。

FR-DIR-003 基文件夹导航
- 行为：支持会话 > 后退 / 前进（在比较过的基文件夹历史中切换）；上一级（左侧/右侧/两侧）；浏览文件夹（左侧/右侧，弹浏览对话框）；交换侧；设为基文件夹（选中文件夹设为其所在侧基）/ 设为基文件夹（另一侧）/ 两个选中文件夹设为当前视图左右基。
- 边界：左右两侧可独立浏览（左右基文件夹路径可互不相关，例如比较 A 的子目录与 B 的另一子目录）。

### 3.1.2 比较基准（会话设置 > 比较）

FR-DIR-010 快速测试（仅读目录项即可判定）
- 比较文件大小：大小不同 → 标记不同。
- 比较时间戳：比较上次修改日期时间；提供"秒容差"（差异超过 N 秒才算不匹配）；"忽略夏令时差异"（忽略正好 1 小时的差异）；"忽略时区差异"（忽略整小时倍数差异）。
- 比较文件名大小写：字符大小写不同 → 标记不同。
- 比较文件属性：比较 Windows DOS 属性（存档 A、隐藏 H、只读 R、系统 S 等；下拉菜单显示参与比较属性的单字母缩写，未参与者显示短横线；任一选中属性有差异即标记不同。默认建议关闭，因为复制文件即可改变存档属性）。
- 比较 Unix 元数据：权限（用户/组/其他 的读/写/执行/粘滞位）、所有者 ID、组 ID。
- 对齐具有不同扩展名的文件名：文件名相同扩展名不同的文件对齐。
- 对齐具有不同 Unicode 规范化形式的文件名：Unicode 等价文件名对齐。

FR-DIR-011 需要读取文件的测试（内容比较）
- 比较内容（三种方式）：
  - CRC 比较：使用文件 CRC32 值比较（zip 等提供预计算 CRC 的资源直接使用，其余按需计算）。
  - 二进制比较：逐字节比较。
  - 基于规则的比较：按文件格式关联比较，可忽略行尾、空白、源代码注释等不重要差异。
- "如果快速测试指示文件相同则跳过"：仅在时间戳不同（等快速项不同）时才执行慢速内容比较，提高速度。
- 比较版本：比较 exe/dll/ocx 等模块头中的版本信息。
- "覆盖快速测试结果"：内容比较判定匹配时，即使时间戳等快速测试有差异也标记为匹配（取消勾选则保留快速测试颜色）。

FR-DIR-012 手动内容比较
- 行为：操作 > 比较内容 对选定项执行内容比较（可选 CRC/二进制/基于规则三种方法之一）。
- 结果枚举：CRC 与二进制比较返回"二进制相同 / 二进制差异"；基于规则比较（内含二进制比较）返回"二进制相同 / 基于规则相同（仅编码或行尾等可忽略差异）/ 不重要的差异 / 重要差异"。
- 触发内容比较的三种时机：会话设置要求自动内容比较；显式执行比较内容命令；在文件会话中打开文件对。

FR-DIR-013 快速比较对话框
- 行为：操作 > 快速比较 显示摘要对话框而非完整并排视图。选中两个文件（无论是否相对）互相比较；选中一个则与对面比较。
- 边界：程序选项可设"以文件比较开始时显示快速比较对话框"，并选二进制或基于规则快速比较，可勾选"如果文件不同则自动打开视图"。

### 3.1.3 对齐规则

FR-DIR-020 默认对齐
- 行为：默认按名称从左到右对齐文件和子文件夹。

FR-DIR-021 忽略文件夹结构（平铺模式）
- 行为：视图 > 忽略文件夹结构 隐藏文件夹树，不管文件在哪个子文件夹中都按名对齐（平铺显示）。
- 边界：与"仅比较文件"等文件夹显示过滤器独立。

FR-DIR-022 手动对齐（标准版可用）
- 行为：右键第一项 > "与之对齐" > 单击第二项强制并排。也可选中两项后执行对齐命令。父文件夹必须并排。
- 相似地，比较不同名文件：单击第一个文件，Ctrl+单击第二个，操作 > 打开（或空格键标记两个后打开）。

FR-DIR-023 对齐覆盖（Pro 专属）
- 行为：会话设置 > 杂项 > 强制使用不同的对齐规则，新建对齐覆盖项：填写"对齐左侧文件(或文件夹)"与"与右侧文件(或文件夹)"掩码；支持 DOS 通配符（`*.gif` ↔ `*.png`、`x*.jpg` ↔ `y*.jpg`、`x.txt` ↔ `x.csv`）或勾选正则表达式使用替换式正则；可用"限制到此文件夹"指定相对路径范围。

### 3.1.4 过滤体系

FR-DIR-030 三类过滤器总览
1. **文件过滤器**：按名称/属性等包含或排除文件（影响比较与操作范围）。
2. **显示过滤器**：按比较状态显示/隐藏行（不影响比较结果）。
3. **文件夹显示过滤器**：控制文件夹何时显示。

FR-DIR-031 名称过滤器
- 行为：会话设置 > 名称过滤器，四个列表（每行一个掩码）：包含文件、排除文件、包含文件夹、排除文件夹。过滤器工具栏编辑支持分号分隔的简单通配符，排除项加前导减号 `-`；可从预设下拉选择；"添加到预设"可保存命名预设（预设列表在程序选项 > 调整 > 名称过滤器预设中定义）。
- 掩码语义（详见 4.4 FR-FLT）：`?` 单字符、`*` 任意字符、`[az]`/`[a-z]`/`[!az]` 集合、`[[]` 匹配 `[`；`f` 文件 f、`p\` 文件夹 p、`-f` 排除、`-p\` 排除文件夹；相对掩码 `p\f`、`.\f`（基文件夹内）、`...\f`（任意深度）；掩码末尾为句点时 `?`/`*` 不匹配句点（支持无扩展名文件过滤）。
- 边界：若文件过滤器隐藏一侧文件但另一侧对应文件应可见，两者都显示，被隐藏者显示为青绿色（配合抑制过滤器语义）。

FR-DIR-032 其他过滤器
- 行为：会话设置 > 其他过滤器，按非名称条件排除文件：修改日期（早于/晚于，绝对或"几天前"相对）、大小（小于/大于，B/KB/MB/GB）、内容（包含/不包含搜索串）、DOS 属性（已设置/未设置某属性）、Unix 文件类型（块设备 b/字符设备 c/符号链接 l/FIFO p/普通文件 r/套接字 s）、版本控制状态（已设置/未设置某状态，需 VCS 提供）。
- 默认勾选"排除受保护的操作系统文件"。
- 定义了其他过滤器项时，文件夹视图底部出现"评论栏"，其上的其他过滤器按钮可编辑这些过滤器。

FR-DIR-033 显示过滤器
- 行为：视图菜单 / 工具栏按钮，将视图限制为某些比较结果：显示全部、只显示差异、只显示相同，及组合（左侧较新、右侧较新、左孤立、右孤立、孤立项目、无孤立的差异等）。
- 工具栏三种内置布局（右键工具栏切换）：
  - 下拉（默认）：全部/差异/相同三按钮 + 中间组合下拉；
  - 收藏：各种过滤器组合按钮一排；
  - 切换：各比较状态独立开关（可表达任意组合，如仅"左孤立 + 右较新"）。
- 显示过滤器选择在离开会话时保存（除非会话被锁定）。实测数据格式：`DisplayFilter Value="[showLeftAdded, showRightAdded, showLeftChanged, showRightChanged, showConflict]"`。

FR-DIR-034 文件夹显示过滤器
- 默认：仅当文件夹包含的至少一个文件可见时文件夹才出现。
- 视图 > 始终显示文件夹：所有文件夹出现（除非被文件过滤器显式排除）。
- 视图 > 比较文件和文件夹结构：文件夹遵守主显示过滤器。
- 视图 > 仅比较文件：抑制所有空文件夹（真正的空文件夹 + 内容全部被过滤隐藏的文件夹）。

FR-DIR-035 抑制过滤器
- 行为：视图 > 抑制过滤器 暂时抑制文件过滤器与显示过滤器；被隐藏的文件/文件夹以青绿色（蓝绿色）显示且可处理。
- 边界：程序选项 > 文件操作 > "默认包括隐藏项目"控制操作（复制/移动/删除）默认是否包含被过滤项；操作对话框可逐次覆盖。

FR-DIR-036 排除命令
- 行为：操作 > 排除 将选定的文件/文件夹从当前会话过滤掉（便捷地写入名称过滤器排除列表）；选择多个同类型文件时提供"排除该类型的所有文件"。移除排除需在名称过滤器中删除条目。

### 3.1.5 显示与列

FR-DIR-040 颜色语义（默认，可在设置 > 外观 > 文件夹视图自定义）
| 颜色 | 含义 |
| --- | --- |
| 灰色 | 未知或较旧 |
| 黑色 | 相同 |
| 紫色 | 孤立（另一侧不存在） |
| 红色 | 较新或不同 |

FR-DIR-041 图标与视觉元素
- 文件名左侧彩色点：即使行被选中遮挡颜色也能给出差异颜色提示。
- 中间列内容比较图标：已执行内容比较时显示结果图标（二进制相同/二进制差异/基于规则相同/不重要的差异/重要差异等，对应 contentsame/contentsamebinary/contentdifferent/contentdifferentbinary/contentsimilar/insigignored 等图示资源）。
- 孤立项在另一侧显示空洞；DOS 属性以文件名后括号字母显示：r 只读、h 隐藏、a 存档、s 系统。
- 压缩包/容器显示"拉链"图标，可双击展开比较其中每个文件。
- 符号链接 / NTFS 连接点文件夹图标带小箭头；打开出错带红色小 X（两者可同时存在）。
- 视图 > 图例 弹出各种文件夹图标颜色组合的指南窗口。

FR-DIR-042 列体系
- 内置列：名称、扩展名、状态（VCS 状态，配置 SCC 时）、修订版（VCS 修订号）、版本（exe/dll 模块头 major/minor/maintenance/build）、大小（文件大小或文件夹内总大小，全部内容加载前为空）、CRC（CRC32；提供预计算的资源直接使用）、已修改（时间戳）、属性（Windows 属性字母或 Unix 模式，与 ls 一致）、所有者（Unix）、组（Unix）。
- Windows 属性字母：A 压缩文档、C 压缩、D 目录、E 已加密、H 隐藏、I 内容未索引、L 符号链接/重解析点、M 访问时需重新调用数据（与 O 配对）、N 正常、O 离线、P 已固定、R 只读、S 系统、T 临时、U 未固定、Z 稀疏。
- 行为：单击列标题按该列排序；右键标题选择显示/隐藏其他列。实测 State 中保存 `SortDown`、`SortSide`。

FR-DIR-043 文件夹处理选项（会话设置 > 处理）
- 在后台自动扫描子文件夹：加载时后台读取文件夹以便未打开前即适当着色；"自动扫描顶级孤立子文件夹"可扫描孤立文件夹以准确报告大小（顶级孤立文件夹通常可不扫描直接着色/过滤，因其只含孤立项）。
- 加载会话时展开子文件夹 / 仅展开具有差异的子文件夹。
- 存档处理三态：始终作为文件 / 打开后作为文件夹（默认：排序如文件带 zip 图标，打开后状态如文件夹反映内容）/ 始终作为文件夹。
- 文件处理：将文件复制到 FTP 站点时修改本地文件时间戳以匹配 FTP 副本；跟随符号链接（符号链接与 NTFS 连接点显示为目标：文件/文件夹属性、大小、时间、属性）；维护 DOS 8.3 别名；复制 NTFS 文件权限（安全描述符；不保留从文本比较编辑的文件权限）；复制创建日期；自动刷新（定期刷新文件夹比较）。

### 3.1.6 选择模型

FR-DIR-050 选择交互
- 单击显示任一侧项目选择之；单击中间列同时选择两侧；Ctrl+单击累加；按住鼠标从第一项滑到最后一项选择范围（滑过中间列则两侧都选）。
- 编辑 > 全选；编辑 > 选择所有文件；Shift+左箭头把选择限制在左侧、Shift+右箭头限制在右侧。
- 编辑菜单（文件夹合并/同步视图同样具备）：全部展开、全部折叠、全选、选择所有文件、选择较新的（左/右/两侧）、选择孤立项目（左/右/两侧）、反选。
- 键盘：定位到文件按空格键标记，再定位第二个按空格（用于比较不同名文件）。

### 3.1.7 文件操作

FR-DIR-060 复制
- 复制到右侧 / 复制到左侧（默认快捷键 Ctrl+R / Ctrl+L）：覆盖目标侧现有文件。
- 复制到一侧：提示方向。
- 复制到另一侧：动态命令，标题图标随选择侧显示。
- 选中文件夹时仅复制其过滤后的内容（等同展开并全选可见内容）；若选中已打开文件夹且其子项也被选中，忽略文件夹选择仅处理子项。
- 默认复制前确认（可关闭"确认文件复制"）；方向明确时（到左/到右）可跳过确认。
- 边界：目标为只读/远程/压缩包时按相应 VFS 能力处理；复制到 FTP 可触发"修改本地文件时间戳"行为。

FR-DIR-061 复制到文件夹 / 移动到文件夹
- 将选中项复制/移动到任意目标文件夹；只能在一侧选择（不能两侧同时）。
- 目标可以是压缩包（如 .zip），不存在时自动创建。
- 路径选项三种：保留相对文件夹结构（最小相对结构，必要时创建中间文件夹）、保留基文件夹结构（完整路径回到基文件夹）、不保留文件夹结构（全部平铺到目标）。
- 脚本对应 `COPYTO` / `MOVETO [left|right|all] [path:(relative|base|none)] <路径>`。

FR-DIR-062 移动与交换
- 移动到右侧 / 左侧 / 一侧 / 另一侧：语义同复制但删除源。
- 交换：选中的两侧项目互相移动到对方侧。默认确认（"确认文件移动"）。

FR-DIR-063 删除
- 删除选定侧或两侧项目；"如果可能使用回收站"复选框（本地驱动器有效；网络驱动器、远程服务、压缩包内忽略）。
- 文件夹语义同复制（仅删除过滤后内容；打开文件夹与其子项同选时忽略文件夹）。

FR-DIR-064 重命名
- 多文件重命名对话框：DOS 兼容（自动计算所选名称重叠的基掩码，`*`/`?` 保留原字符生成唯一名，如 `abc?.bak`）或正则表达式（旧掩码匹配原名，新掩码模板含 `$1` 反向引用，如 `.*(\d\.txt)` → `xyz$1`）。

FR-DIR-065 属性与修改时间
- 属性对话框：Windows 修改 DOS 属性（只读、隐藏、存档；不能修改系统属性）；macOS/Linux 修改所有者与组访问权限。三态复选框（勾=全部启用、空=全部禁用、灰=部分启用）。只修改文件夹本身不改内容；改内容需展开并选中内容。
- 修改时间（Touch）：从另一侧复制时间戳，或设为任意日期时间（日历初始值为当前系统时间或上次修改时间，仅初始化仍可改）；文件夹仅改自身时间戳不改内容时间戳；操作系统不允许改文件夹时间戳时失败报错。

FR-DIR-066 其他操作
- 新建文件夹：选中文件/关闭文件夹时在其父文件夹创建；选中打开文件夹时创建为其子文件夹；两侧都选则两侧都创建；名称带 `.zip` 等扩展名可创建压缩包；直接在路径编辑输入新路径回车可创建新基文件夹（警告对话框确认）。
- 复制文件名：将选定项目路径列表复制到剪贴板。
- 忽略：抑制选定项目中的差异（视图与操作均按相同处理）。
- 刷新选择 / 刷新（打开的文件夹）/ 完全刷新（整个比较）。
- 源代码控制子菜单（Pro，需配置 SCC 提供程序且所选项目均在控制下）：添加到源代码控制、从源代码控制中移除、获取最新版本、获取（特定版本）、签入、签出、撤消签出、显示差异、显示历史、显示属性、运行源代码控制应用程序。
- 资源管理器：显示文件管理器对选定项的上下文菜单。

FR-DIR-067 同步子菜单（文件夹比较内的快捷同步）
- 更新右侧：较新 + 孤立项从左复制到右。
- 更新左侧：反之。
- 双向更新：两个方向的较新 + 孤立项互相复制。
- 镜像到右侧：替换右侧所有不同项、删除右侧孤立项、复制左侧孤立项到右侧。
- 镜像到左侧：反之。
- 同步确认行为可配置（提示 / 全部是 / 全部否）。

FR-DIR-068 操作遵循过滤器
- 默认操作（复制/移动/删除/交换等）遵循当前文件过滤器与显示过滤器（被过滤内容跳过）；可在程序选项改为默认包含隐藏项；操作对话框可逐次覆盖。

### 3.1.8 打开子会话与自动选型

FR-DIR-070 打开（双击 / 操作 > 打开）
- 项目是文件夹 → 展开/进入子文件夹比较。
- 项目是压缩包 → 展开为文件夹比较。
- 项目是文件 → 在新视图中以文件格式列表决定的视图类型打开（文本/表格/十六进制/图片/媒体/版本/注册表/外部程序）。
- 恰好选择两个项目（无论是否相对）→ 在新视图比较它们；只选一个 → 与对面项目比较。
- 打开方式：指定文件会话类型打开，或在"打开方式应用程序"列表（含关联程序、文本编辑、文本补丁、用户自定义外部程序）中打开。外部程序修改项目后文件夹比较不自动更新。

FR-DIR-071 子会话导航（差异文件遍历）
- 搜索 > 下一个差异文件 / 上一个差异文件：跳到父文件夹会话中下一对有差异的文件。
- 复制文件到右侧并打开下一个差异 / 复制文件到左侧并打开下一个差异：整文件复制后自动跳到下一个差异文件。
- 程序选项 > 下一个差异：加载新文件时转到第一个差异；复制到另一侧后转到下一个差异；"下一个差异文件"可限制在当前文件夹；回绕到第一个差异；未找到差异时抑制消息面板（与蜂鸣）。

FR-DIR-072 会话内信息与报告
- 会话 > 文件夹比较信息：显示比较统计信息。
- 会话 > 文件夹比较报告：见 4.7 报告。
- 会话 > 合并基文件夹 / 同步基文件夹：基于当前基打开文件夹合并/同步会话。
- 会话 > 比较父文件夹：基于基的父文件夹打开新文件夹比较。
- 会话 > 锁定：锁定会话（图标变化；锁定会话离开时不保存显示过滤器等状态变更）。

## 3.2 文本比较（Text Compare）

### 3.2.1 功能定位与显示

FR-TXT-001 并排/上下双窗格文本比较

### 3.2.2 比较规则

FR-TXT-010 重要性设置（会话设置 > 重要性）
- "不重要"列表：勾选匹配项视为不重要——含当前文件格式定义的全部语法元素（如注释、字符串、关键字）。
- 空白三类：行首空白、嵌入空白、行尾空白各自可设重要/不重要。
- "其他所有内容"（非空白非语法元素文本）区分大小写开关：勾选"字符大小写"则大小写差异重要。
- "编辑语法"按钮跳转到当前文件格式的语法定义。
- 其他：孤儿行始终很重要（额外空行或仅含不重要文本的行视为重要差异）；比较行尾（PC/Mac/Unix）——默认忽略行尾样式差异，勾选后逐行比较行尾。

FR-TXT-011 对齐设置（会话设置 > 对齐）
- 不对齐：不根据内容对齐行。
- 标准对齐（默认）：比较每个文件的连续较小部分对齐；各部分可在整个比较完成前渐进显示。
- Myers O(ND)：LCS 算法；大插入、大量重复文本时匹配更好；文件一次性比较（比较完成前不显示，大文件慢）；不支持相似性比较（不匹配分组为块）。
- Patience Diff：Bram Cohen 算法。
- 从不对齐差异：重要差异行显示为"添加 + 删除"的文本块而非"更改"。
- 偏斜容差：查找特定行匹配时检查的最大行数；增大改善大间隙对齐但更慢。
- 使用接近度匹配：按相似度尝试对齐剩余不匹配行。
- 手动对齐：右键一行 > 与之对齐 > 单击另一侧一行强制并排（可多行选择）；编辑 > 隔离：重新对齐使选定行独立。
- 边界：算法仍可能不理想 → 手动对齐是兜底。

FR-TXT-012 替换（Pro 专属，会话设置 > 替换）
- 行为：识别应视为不重要的重复性更改。定义"一侧匹配文本"与"另一侧替换文本"（如左 `apple` ↔ 右 `orange` 视为不重要）。每项可设：区分大小写、全字匹配、正则表达式（替换式）、生效侧。
- 触发：会话设置新建替换项；或在差异处 编辑 > 替换（根据当前差异将项添加到替换列表）。

FR-TXT-013 格式与编码
- 会话设置 > 格式：为左/右侧分别指定文件格式（默认自动检测——按掩码匹配文件格式列表）。
- 编码覆盖：会话覆盖每文件使用的字符编码（默认无 → 使用文件格式的编码选择）。
- 文件格式转换（见 4.5）：加载/保存外部转换程序、编码自动检测、Ctrl+Z EOF 标志、每行字符限制（超长断行，保存时删除人工换行）、保存时删除尾部空白/行首空格转制表符。

FR-TXT-014 规格
- 会话设置 > 规格：指定左右文件；"禁用编辑"防止内容在磁盘被更改；描述字段。

### 3.2.3 编辑能力

FR-TXT-020 全功能编辑器
- 每个窗格是完整文本编辑器：输入即编辑，比较实时动态更新。
- 撤销 / 重做。
- 编辑命令：剪切/复制/粘贴/删除；复制到右侧/左侧（选定行或当前部分）；复制行到右侧/左侧；复制到另一侧（动态）；增加/减少缩进；删除行、删除到行首/行尾、删除单词、删除到单词开头/结尾、在前面/后面插入行（多数默认隐藏，可自定义快捷键）。

FR-TXT-021 转换文件（整文件级编辑工具）
- 删除尾部空白；行首空格转制表符（按制表位）；制表符转空格（按制表位）；行尾字符（更改所有行的行尾样式 Windows/Unix/Mac）。

FR-TXT-022 查找与替换
- 查找面板选项：正则表达式（PCRE，"插入正则表达式元素"下拉辅助）、区分大小写、全字匹配、循环搜索、侧（搜索哪一侧）、自动关闭。下一个按钮定位；"全选"按钮选中所有包含匹配的行。
- 查找下一个 / 查找上一个继续。
- 替换对话框同选项。
- 转到：定位到指定行和列。

FR-TXT-023 书签

## 3.3 文本合并（Text Merge，三向，Pro 专属）

FR-TMRG-001 视图结构
- 2-3 个不可编辑源窗格（左、右、可选中间=公共祖先）+ 1 个可编辑输出窗格（下方）。可临时隐藏中间窗格给左右让空间；"分离输出窗格"将输出移到独立窗口（可放第二显示器）。
- 支持自动换行（BC5）。
- 触发：命令行 3 个文件（左 中 右顺序：`left right center`——`/center=` 显式指定）或 4 个文件（+输出）；文本比较视图 会话 > 合并文件；`-fv="Text Merge"`。

FR-TMRG-002 状态与颜色
- 左侧更改蓝绿色（青色）、右侧更改洋红色、重叠更改（冲突）红色；相同更改不算冲突。输出中被手动编辑的部分黄色。
- 显示过滤器（合并专用）：显示全部 / 只显示更改 / 只显示冲突 / 只显示左侧更改 / 只显示右侧更改（含组合语义：如"只显示左侧更改"实际显示相同更改+左侧更改+左右不同更改+冲突行）。

FR-TMRG-003 冲突检测与配置
- 默认：同一部分文本在左右两侧都有更改且彼此不同 → 冲突；左右相同更改 → 非冲突自动合并。
- 对齐设置中的"合并冲突是"：仅更改不同的行；或左侧更改和右侧更改之间用 N 行分隔即视为冲突（N 可配，将彼此接近的更改与直接冲突一起标记供审查）。

FR-TMRG-004 自动合并与采用（Take）
- 加载时输出自动构建：能自动采用的非冲突更改自动应用；否则输出与中间内容一致。每个更改按来源窗格颜色显示。
- 采用命令（工具栏 / 编辑弹出菜单 / 输出窗格每部分旁按钮）：取左侧 / 取中间 / 取右侧（选定行或当前部分）；先取左侧再取右侧 / 先取右侧再取左侧（按顺序都取）；取左/中/右侧行（单行粒度）。
- "下一个左侧取 / 下一个右侧取"导航：跳到指示侧被取的下一个行范围。

FR-TMRG-005 输出编辑与冲突处理
- 可直接编辑输出窗格（部分变黄）；再次"采用"可还原为某输入。
- 编辑 > 冲突：清除或设置选定行或当前部分的冲突状态（手动重判冲突）。
- 查找 > 清除冲突部分，下一个：清除当前部分冲突并定位下一个冲突部分；下一个/上一个冲突部分导航。
- 命令行 `/automerge`：无冲突时无需交互自动合并；`/force` 用 CVS 样式标记写冲突；`/reviewconflicts` 发现冲突时打开文本合并视图；`/favorleft|right` 在受惠侧绘制非冲突更改，不重要冲突自动从受惠侧采用。

FR-TMRG-006 输出保存
- 会话设置 > 规格：指定左右中文件与"合并到"目标文件。
- 输出文件任何先前副本被忽略：会话前存在或会话中被更改的内容在保存时丢失（需警示 UI）。
- 保存前自动备份可配置（备份选项 + `/nobackups` 开关）。

FR-TMRG-007 会话命令
- 与输出比较 >（左/中/右）：新文本比较会话中比较该侧与输出。
- 合并父文件夹：基于当前文件父文件夹打开文件夹合并。
- 下一个/上一个差异文件、取左/右侧文件并打开下一个差异（子会话批量流程）。
- 文本合并信息：合并统计。
- BC5：手动对齐支持多行选择。

## 3.5 文件夹同步（Folder Sync）

FR-SYNC-001 专用同步界面
- 上部：左基文件夹、右基文件夹（可为远程服务）+ 同步方法下拉 + 规则按钮（打开比较设置）+ 过滤器。

- 视图 > 日志面板；下一个/上一个冲突导航；查找文件名。

FR-SYNC-002 预设同步方法（5 种）
| 方法 | 行为 |
| --- | --- |
| 更新右侧 | 较新的和孤立的项目从左复制到右 |
| 更新左侧 | 较新的和孤立的项目从右复制到左 |
| 双向更新 | 两个方向的较新 + 孤立项互相复制 |

- 文件夹级（汇总）：右侧文件夹包含将复制到左侧的文件 / 左侧→右 / 左侧文件夹包含将删除的文件 / 右侧→左删 / 左侧文件夹包含将复制到右与将删除的文件 / 右侧组合。
- 可逐项修改操作：操作菜单或右键改"保持不变 / 复制到左 / 复制到右 / 删除左 / 删除右"等。

FR-SYNC-004 同步设置（会话设置）
- 同步选项卡：预设/自定义方法。
- 比较选项卡：与文件夹比较一致的比较基准。
- 处理选项卡：同步空文件夹（影响无内容或内容全部被过滤掉的文件夹）；加载时展开子文件夹；在压缩文件中同步（压缩包视为普通文件夹）；尽可能删除到回收站；复制到 FTP 时 touch 本地文件；遵循符号链接；DOS 8.3；NTFS 权限；创建日期；自动刷新。
- 名称过滤器 / 其他过滤器 / 杂项同文件夹比较。

FR-SYNC-005 会话命令
- 运行同步（执行所有同步操作）；文件夹同步信息（统计）；比较基文件夹 / 比较父文件夹（转文件夹比较）；交换侧；抑制过滤器（显示不受同步影响的项目）。

FR-SYNC-006 脚本对应
- `sync [visible] [create-empty] (update|mirror):(left->right|right->left|all)`：visible=仅影响可见（已展开）文件；create-empty=创建空文件夹；update 方向 all 表示双向；mirror 的 all 无效。

## 3.6 表格比较（Table Compare）

FR-TBL-001 网格比较
- 行为：以并排或上下布局比较含表格数据的文本文件（CSV、制表符分隔、HTML 表格、Excel 工作表），两个网格同步滚动，逐单元格比较。
- 显示"比较列"而非数据文件物理列：如第一比较列可以是左文件第 3 列对右文件第 5 列。
- 沟通槽（gutter）颜色点表示每行整体状态：红 = 重要差异、蓝 = 不重要差异。

FR-TBL-002 工作表（Sheet）支持（BC5 增强）
- 多工作表文件：视图底部选项卡切换比较工作表；比较同一文件中的两个工作表：两侧打开同一文件后在会话设置 > 工作表中用上移/下移对齐左右工作表。
- 工作表对齐方式：未对齐（两侧文件顺序）/ 按左侧名称对齐 / 按右侧名称对齐 / 自定义对齐（上移下移，整理删除空行）。
- HTML 表格文件格式：多表格选项卡视图；选项卡颜色点表示每个工作表比较状态；红点选项卡配"下一/上一差异行"遍历。

FR-TBL-003 列设置
- 列对齐：未对齐（两侧文件顺序）/ 按左侧名称对齐 / 按右侧名称对齐 / 自定义对齐（上移/下移调整比较顺序；整理清除空行）。
- 键列：任意比较列组合可定义为键；有键时仅键列数据匹配的行对齐；多键时优先级按比较顺序；无键时用行选项卡的对齐设置。
- 列处理对话框（每列或默认）：键复选框；使用默认复选框；类型——常规（自动确定列类型）/ 文本 / 日期 / 数值：
  - 文本：不重要复选框（整列不重要）；字符大小写（ABC=abc）；空白（单词前后/之间空格数）不重要。
  - 日期：日期容差（相差给定数量内视为不重要）。
  - 数值：数值容差（数字相差 ≤ 容差视为不重要）。

FR-TBL-004 行对齐设置（无键时）
- 未对齐 / 标准对齐 / Myers O(ND) / Patience Diff；从不对齐差异；偏斜容差；使用接近匹配（相似度对齐剩余不匹配行）；对齐前排序行（重新排序后再对齐）；每工作表可清除"使用默认"单独设置；"编辑默认"改默认行对齐。

FR-TBL-005 表格文件格式（Table Format）
- 常规（掩码+描述）、转换、类型（列分隔定义：如 CSV/制表符/自定义分隔）、区域（数字/日期的区域解析）四选项卡（对应 formattable*.html）。

FR-TBL-006 命令与报告
- 导航：下一/上一差异（单元格/行粒度）、差异部分、差异文件、复制并打开下一个差异。
- 复制到另一侧（单元格/行）；显示全部/差异/相同；忽略不重要差异。
- 报告：data-report（side-by-side / summary / interleaved 布局）。

## 3.7 十六进制比较（Hex Compare）

FR-HEX-001 十六进制视图
- 并排/上下布局，以十六进制编辑器典型表示法逐字节显示并比较两个文件的原始内容（字节地址 + 十六进制列 + ASCII 列）。
- 视图：字节地址显示/隐藏；当前字节地址显示；小端/大端值解释（首字节最低/最高有效位列出多字节值）。

FR-HEX-002 对齐算法
- 完全：复杂算法对齐字节（插入/删除感知）。
- 快速：更简单更快的对齐，适合大文件。
- 无：逐字节对齐。
- 设置"小于此大小的文件在加载时不锁定文件"允许其他程序编辑较小文件。

FR-HEX-003 编辑与操作
- 每窗格为十六进制编辑器：内联编辑动态重比较；撤销/重做；复制到右侧/左侧（选定字节）；剪切/复制/粘贴/删除；全选（所有可见字节）。
- 查找/替换（文本或十六进制模式）；转到指定字节。
- 显示过滤器：显示全部 / 只显示差异 / 只显示相同。
- 报告：hex-report（side-by-side / summary / interleaved；line-numbers 选项在此为字节地址）。

## 3.8 图片比较（Picture Compare）

FR-PIX-001 支持格式
- 内置关联：GIF、ICO、JPEG、JPG、PNG、TIFF、BMP。
- 依赖操作系统版本与第三方编解码器可另处理：PDF、RLA/RPF、ICNS、CEL/PIC、Camera RAW（3fr/arw/cr2/…/srw 等 25+ 扩展名）、CUT、EPS、FAX（efx/fax/g3…）、JPEG 变体（jpeg/jpe/jfif/exif）、JPEG 2000（jp2/jpf）、JPEG XR/HD Photo（jxr/wdp）、PCD、PICT、MacPaint、Misc（cur/epi/exr/hdr/jps）、Netpbm（pbm/pgm/ppm）、PSD/PDD、PS、QuickTime image、SGI、TIFF 变体、Targa（tga/icb/vda/vst/win）、DIB/MSK/RLE、EMF/WMF、XPM、PCX/SCR。
- 约束：仅比较 32 位每像素（bpp）数据；不支持 HDR、宽色域和额外颜色空间。

FR-PIX-002 三种比较模式
- 容差模式：差异像素分三类——匹配（灰）、不重要差异（蓝，≤ 容差）、重要差异（红）；容差可配置；可定义替换（颜色替换表：一侧颜色 → 另一侧颜色视为不重要）；"忽略不重要的差异"把 ≤ 容差差异当匹配。
- 不匹配范围模式：黑 = 匹配、黄 = 差异，亮度表示差异程度。
- 混合模式：按可配置混合百分比叠加两图（类似淡入淡出/blink 的静态版），减小百分比右侧更主导。

FR-PIX-003 几何对齐
- 自动缩放：放大较小图像匹配较大图像比例。
- 旋转：顺/逆时针 90 度。
- 翻转：水平/垂直（相对中心交换像素）。
- 差异偏移（裁剪对齐）：在差异窗格上拖动鼠标调整右图左上角位置；单击偏移标签或"重置差异偏移"回到 (0,0)；箭头键一次一像素微调（需焦点在差异窗格）、Ctrl+箭头大步移动。

FR-PIX-004 显示辅助
- 缩放：放大/缩小、缩放到适合、实际像素。
- 像素缩略图：光标处像素的放大视图与 RGB 值。
- 透明区域以棋盘格显示（选项）。
- 颜色自定义：容差模式下相同/不同/相似像素颜色。
- 报告：picture-report（side-by-side / summary；ignore-unimportant）。

## 3.9 媒体比较（Media Compare，原 MP3 比较）

FR-MED-001 范围
- BC5：支持 FLAC、MP3、MP4/AAC（4.x 称 MP3 比较；官网特性页另提 OGG 标签）。
- 比较音频文件的标签（元数据）信息，列表式并排显示；重要/不重要项目级差异着色。

FR-MED-002 操作
- 播放（单侧音轨）；播放两个（同时播放两条音轨以听觉对比）。
- 项目重要性：将选定项目标记为重要/不重要；忽略不重要的差异。
- 导航：下一/上一差异项、差异文件、复制文件到另一侧并打开下一个差异。
- 报告：media-report（side-by-side / summary）。

## 3.10 注册表比较（Registry Compare，Pro 专属）

FR-REG-001 对象

FR-REG-002 显示与比较
- 键和值按名称排序和对齐；键按其包含的差异/孤立项着色；值着色突出字符差异：红 = 差异、紫 = 孤立。

FR-REG-003 编辑

## 3.11 版本比较（Version Compare）

FR-VER-001 对象与内容
- 比较 exe/dll/ocx 等模块版本资源中的字段：公司名、产品名、文件描述、版本号（major/minor/build）等头部字段（BC5 扩充了支持的头部字段并改进 MUI 处理）。

FR-VER-002 操作

- 忽略不重要差异；显示全部/差异/相同；文本详细信息面板；字体与布局切换。
- 只读（重新加载文件、重新比较不重载；无编辑命令，仅复制/全选）。
- 报告：version-report（side-by-side / summary）。

## 3.12 剪贴板比较（Clipboard Compare）

FR-CLIP-001 后台监视

FR-CLIP-002 快捷比较

FR-CLIP-003 选项
- Windows 启动时运行；启用键盘快捷键；关联文件格式掩码（如 `*.java`，为文本比较选择合适文件格式，留空用默认）；最小剪辑长度（字符数，防保存密码等短文本，0 = 全部保存）；存储限制（条数上限）；存储限制（MB 内存上限；即使超限也尽量保留最近两条）。

FR-CLIP-004 其他剪贴板入口

FR-PATCH-001 补丁查看

## 4.4 过滤器通用语义（File Masks）

FR-FLT-001 通配符语义
- `?` 匹配任意单字符；`*` 匹配零或任意数量字符；`[az]` 集合内单字符；`[a-z]` 范围；`[!az]` 集合外；`[[]` 匹配 `[`。
- `*.*` 因历史原因匹配任何文件名（包括无扩展名）。
- 掩码末尾句点（`*.`）时 `?`/`*` 不匹配句点 → 仅无扩展名文件。

FR-FLT-002 简单与相对掩码
- `f` 命名为 f 的文件；`p\` 命名为 p 的文件夹；前导 `-` 排除（`-f`、`-p\`）。
- 相对掩码：`p\f`（f 须在 p 内）、`.\f`（基文件夹内）、`...\f`（任意层级下的 p 内）。基文件夹始终包含；包含文件的父文件夹链自动包含。
- 多掩码分号分隔；过滤器工具栏快捷语法：排除用前导减号。

## 4.5 文件格式体系

FR-FMT-001 文件格式概念与列表
- 文件格式决定：可视化比较的视图类型；比较/保存前执行的转换；语法/语法元素；语法元素大小写敏感性；制表位；帮助对齐的行权重。
- 文件格式列表（Beyond Compare > 文件格式）：顺序重要，自上而下扫描，第一个掩码匹配且启用的格式生效；上移/下移排序；勾选启用。
- 被列表更高项遮蔽的格式显示红色；禁用项灰色；空掩码项不匹配任何文件（仅能文件会话手动选择）。
- 会话可覆盖格式启用状态（文件夹会话杂项）。
- 官网下载区提供附加文件格式（如 HTML 表格格式）。

FR-FMT-002 文本格式（4 选项卡）
- 常规：掩码、描述。
- 转换：转换方法（无/外部程序/内置转换器如 Word/PDF/RTF→文本、Delphi 二进制窗体→文本）；外部程序加载命令行（变量：`%s` 源文件、`%t` 目标文件、`%o` 原始文件；退出码 0 且产物非空才算成功；文件名编码 Unicode/ANSI）；保存转换（取消"禁用编辑"后可配）；编码自动检测或指定代码页；Ctrl+Z(0x1A) 作为 EOF；每行字符限制（超长断行显示，保存时去除人工换行）；保存时删除尾部空白、行首空格转制表符。
- 语法：语法元素列表（元素名 + 若干语法项，列表顺序即优先级）；行权重（对齐算法优先对齐高权重匹配行）。
- 其他（杂项）：插入空格而不是制表符；制表位；行是独立的（每行独立记录，连续差异不作为部分）；基于列的数据（逐列比较）。

FR-FMT-003 语法项类型（编辑语法项对话框）
- 元素名称：下拉现有或新建。
- 基本类别：文本匹配串（可正则、可区分大小写）。
- 分隔类别：起始/结束分隔符（或起始 + 到行尾）；可指定转义字符（如 `\` 允许内嵌结束分隔符）；可正则、可区分大小写。
- 列表类别：逐行 token 列表（可正则、可区分大小写）。
- 列类别：起始列-结束列（或起始列-到行尾）。
- 行类别：页面标题（匹配每页顶部标题，通常换页字符；"或第 1 行"处理首页；指定标题行数）——用于比较报表输出时忽略整体漂移的页标题。
- 元素级"此元素区分大小写"。
- 限制：语法定义不支持嵌套或上下文相关定义（不能很好处理 HTML/PHP 类标记语言）。

FR-FMT-004 表格/十六进制/图片格式
- 表格格式：常规/转换/类型（分隔符）/区域（区域解析）。
- 十六进制格式：常规/转换。
- 图片格式：常规/转换。

FR-FMT-005 外部格式（External Format）
- 用其他应用程序比较文件：掩码、描述 + 四条命令行：快速比较命令行（基于规则比较结果用；返回 0=匹配、1=不匹配）、比较视图命令行、快速合并命令行、合并视图命令行。

## 4.9 脚本处理器（Scripting）

FR-SCR-001 脚本语言
- 纯文本脚本，每行一条命令；大小写不敏感；`#` 后为注释；空行忽略；行尾 `&` 续行；含空格参数加引号。
- 参数引用：`%1`..`%9` 引用命令行参数（脚本名与 `/` 开头的开关不计入）；环境变量 `%VAR%`（大小写敏感）；动态变量 `%date%`（yyyy-mm-dd）、`%time%`（区域相关）、`%fn_time%`（hh-mm-ss 文件名安全）。
- 运行：`bcompare @"脚本.txt"`；脚本无 UI 操纵一个"不可见文件夹会话"：操作需先 SELECT，"显示"由 FILTER 限制，EXPAND 递归进入；文件夹参数可为本地/网络/远程服务/压缩包/快照。
- 状态窗口显示进度与错误（/silent 隐藏）；完成时蜂鸣/关闭可配置；共享脚本文件夹（当前文件夹找不到脚本时回退查找）。
- 调度：系统计划程序调用 `BCompare @同步.txt`，"起始于"设脚本目录。

FR-SCR-002 脚本命令集（31 个）
ATTRIB、BEEP、COLLAPSE、COMPARE、COPY、COPYTO、CRITERIA、DELETE、EXPAND、FILE-REPORT、FILTER、FOLDER-REPORT、HEX-REPORT、LOAD、LOG、MEDIA-REPORT、MOVE、MOVETO、OPTION、PICTURE-REPORT、REGISTRY-REPORT、RENAME、SELECT、SNAPSHOT、SYNC、TABLE-REPORT、TEXT-REPORT、TOUCH、VERSION-REPORT（TABLE-REPORT 亦名 data-report）。

关键命令规格（摘自 scripting_reference.html，缩写 left→lt、right→rt 允许）：

- `ATTRIB (+|-)<属性集> [...]`：a/s/h/r DOS 属性（仅 Windows）。例：`attrib +h`、`attrib +sh -a`。
- `BEEP`：蜂鸣（无视 /silent）。
- `COLLAPSE all | <路径...>`：折叠全部或指定文件夹（相对基文件夹，无通配符）。
- `COMPARE [CRC|binary|rules-based]`：比较当前选择内容（默认用最近比较类型；只比较一次；改判定标准用 CRITERIA）。
- `COPY (left->right|right->left)`：复制选中项。
- `COPYTO [left|right|all] [path:(relative|base|none)] <路径>`：复制到指定路径（默认 all、path:none）。
- `CRITERIA [attrib:<集>] [version] [timestamp[:[Nsec][;IgnoreDST]]] [size|CRC|binary|rules-based] [timezone:(ignore|(left|right)(+|-)<0..12>)] [follow-symlinks] [ignore-unimportant] [owner] [group] [permissions]`：设置全部比较条件。例：`criteria attrib:sh timestamp:2sec;IgnoreDST rules-based timezone:left+6`。
- `DELETE [recyclebin=(yes|no)] (left|right|all)`：删除（回收站仅本地支持处有效）。
- `EXPAND all | <路径...>`：展开（被文件过滤器排除的子文件夹不展开；SELECT 前须展开）。
- `FILTER <掩码>` / `filter cutoff:([<|>](<时间戳>|<N>days)|none)` / `filter size:([<|>]<N>[KB|MB|GB|TB]|none)` / `filter attrib:((+|-)<属性集>|none)` / `filter exclude-protected|include-protected` / `filter unixtype:((+|-)<集合>|none)`：名称（排除前导 `-`、文件夹尾 `\`、相对语义同 4.4）、日期（相对"几天前"或绝对时间戳，宽松解析，含空格加引号）、大小、DOS 属性（a c e h i l o p r s t u z）、受保护 OS 文件、Unix 类型（b c l p r s）过滤。例：`filter "*.txt;-我的文件夹\" attrib:+r`。
- `FOLDER-REPORT layout:(side-by-side|summary|xml) [options:...] [title:] output-to:(printer|clipboard|<文件名>) [output-options:...]`：见 4.7；display-* 标志集见上表。
- `HEX-REPORT` / `MEDIA-REPORT` / `PICTURE-REPORT` / `REGISTRY-REPORT` / `TABLE-REPORT(data-report)` / `TEXT-REPORT` / `VERSION-REPORT` / `FILE-REPORT`：见 4.7 布局与选项。
- `LOAD <会话>` | `load [create:(all|left|right)] <左路径> [<右路径>]` | `load <default>`：加载会话（用其全部设置，显示过滤器除外）/基文件夹（用当前活动设置，默认程序默认值）/默认新比较；基文件夹不存在可 create；加载失败脚本终止。
- `LOG [none|normal|verbose] [[append:]<文件名>]`：日志开关与级别；append 追加；默认当前文件夹 Log.txt。
- `MOVE (left->right|right->left)`；`MOVETO`（同 COPYTO 语义）。
- `OPTION stop-on-error`；`option confirm:(prompt|yes-to-all|no-to-all)`：错误处理与确认策略。
- `RENAME [regexpr <旧掩码>] <新掩码>`：DOS 或正则多文件重命名。例：`rename regexpr (...)(...)\.txt $2$1.txt`。
- `SELECT <掩码...>`：掩码 = `all` | `[(left|right|all).][(exact|diff|newer|older|orphan|all).][(files|folders|all)]` | `empty.folders`；多掩码并集。例：`select newer.files right.older.files`；`select left.diff.files left.orphan.files`。
- `SNAPSHOT [save-crc] [save-version] [expand-archives] [follow-symlinks] [include-empty] [no-filters] (left|right|path:<路径>) [output:<目标>]`：保存快照；目标为完整文件名则用之，无扩展名加 .bcss，目标为文件夹则生成 `folder_YYYY-MM-DD.bcss`（重名自动加序号防覆盖）。
- `SYNC [visible] [create-empty] (update|mirror):(left->right|right->left|all)`。
- `TOUCH (left->right|right->left)` | `touch (left|right|all):(now|<时间戳>)`：复制时间戳或设为当前/指定时间（需先选择）。

FR-SCR-003 报告公共参数
- `title:<标题>`；`output-to:(printer|clipboard|<文件名>)`；`output-options:`——printer：print-color/print-mono、print-portrait/print-landscape；换行：wrap-none/wrap-character/wrap-word；HTML：html-color/html-mono/html-custom（+样式表路径/URL，用于 clipboard 与文件输出）。
- `<comparison>` 可选参数：报告命令可直接携带会话名或一对文件名（不依赖脚本当前选择；会话类型必须匹配报告类型）。

## 4.10 虚拟文件系统与远程服务（VFS）

FR-VFS-001 统一文件系统抽象
- 本地与网络驱动器（UNC `\\server`、`smb://`）、FTP、FTPS（Pro）、SFTP（Pro）、WebDAV、Amazon S3、Dropbox、OneDrive（命名 profile）、Subversion 仓库（svn://、svn+http(s)://、svn+ssh://、可带 @rev 修订号）、MTP 便携设备、HTTP（单文件）、剪贴板（clipboard://）、实时注册表（reg:\\）、压缩包内部、快照文件——全部以统一"规格"寻址（见 2.5），文件夹比较/操作透明作用。

FR-VFS-002 命名配置文件（Profiles）
- Beyond Compare > 配置文件 管理命名配置文件；FTP 有 `<default>` 配置文件供命名配置文件继承全局设置。
- 云存储（Dropbox/OneDrive）需 OAuth 授权（登录、复制网页代码粘贴回 BC）；Amazon S3、WebDAV、Subversion（URL+修订版+凭据）各自设置页。
- 凭据与设置存为命名集合；管理策略可禁用远程配置文件或禁止保存密码。

FR-VFS-002a FTP/FTPS/SFTP 配置文件设置明细（六页）
- **登录页**：协议（FTP / FTP over SSL / SSH SFTP）、端口覆盖、主机、用户名、密码、保存密码（弱加密存储）、描述。
- **连接页**：同时连接数（1-10 并发）；读取超时（秒，期间无字节则失败）；被动传输 PASV（防火墙场景，非所有服务器支持）；限制主动传输(PORT)端口范围（防火墙放行配置用）；登录前使用 HOST 命令（虚拟 FTP 主机）；明文控制通道(仅 SSL)；明文数据通道(仅 SSL，传输提速)；限制 TLS/SSL 版本范围（默认自动尝试含最新并可回退，可锁定以解决握手问题）。
- **传输页**：传输类型 ASCII / 二进制 / 自动（按扩展名自动切换；ASCII 模式服务器自动调整行尾，支持 EBCDIC→ANSI 与记录尾行终止符——大型机场景）；上传时复制时间戳；上传时复制 Unix 权限；压缩传输 MODE Z（服务器支持时；快速连接上可能反而降速）；限制下载/上传带宽（Kbps，每连接）；使用 OpenSSH 服务器的激进上传（更大传输缓冲与流水线，非所有服务器兼容）。
- **列表页**（FTP 目录列表无统一标准，需协商解析）：链接解析——快速（带扩展名视为文件、其余视为文件夹，零额外传输）/ 简单（逐个尝试 CWD 判定）；LIST 选项——MLSD（高分辨率时间戳，成功则忽略后续选项；软链接列为普通文件、列表不递归）、显示隐藏[-a]、强制长格式[-l]（列表为空时尝试）、完整时间戳[-T]（含秒）、解析链接[-L]、递归[-R]（单命令递归列表，首响应慢但总体省时）；其他——隐藏 VMS 版本（仅最新版本参与对齐）、获取不完整的时间戳（列表仅含日期时补查修改时间，牺牲性能换精度，非所有服务器支持）。
- **服务器页**：文件名区分大小写（对齐要求）；编码（目录列表与命令的字符编码）；时区（服务器时区，时间戳自动转本地）；自定义登录命令（连接后发送，SFTP 不支持）。
- **代理页**：使用代理（FTP 代理协议，LAN/WAN 内不勾）；代理类型（防火墙类型）；主机、端口、用户名、密码。
- **全局页**（default 配置文件）：匿名登录电子邮件（匿名密码用）；SSH 公钥认证——私钥文件（OpenSSH / SSH.COM / PuTTY / PGP 格式；ssh-agent 与 pageant 密钥自动使用）、"创建密钥"生成新密钥对；SSL 客户端证书（创建自签名证书）；ASCII 类型扩展名列表（哪些扩展名按 ASCII 传输）。

FR-VFS-002b 其他服务配置文件
- WebDAV：URL、用户名、密码、递归列表、描述。
- Amazon S3：身份验证类型——保存的 S3 凭据（访问密钥 ID + 秘密访问密钥）/ 从凭据文件加载（AWS SDK/AWS CLI 的 `%UserProfile%\.aws\credentials`、`~/.aws/credentials`，尊重 `AWS_SHARED_CREDENTIALS_FILE`、`AWS_CONFIG_FILE` 环境变量与 config 文件，Profile 名缺省 default，支持限时安全令牌）/ 从环境变量加载（`AWS_ACCESS_KEY_ID`、`AWS_SECRET_ACCESS_KEY`、`AWS_SESSION_TOKEN`，否则回落凭据文件 + `AWS_PROFILE`）；存储桶（可选，无列举全桶权限时直接指定）；描述。
- Dropbox / OneDrive：OAuth 授权 + 描述。
- Subversion：版本库 URL、修订版、凭据、描述。

FR-VFS-003 压缩包支持
- 支持格式及默认掩码：7z(含 .7z.001)、BC 快照(.bcss/.bcs)、BZip(.bz/.bz2)、BZipped Tar(.tbz/.tbz2/.tar.bz2)、Compiled HTML Help(.chm)、Debian(.deb)、Disk Image(.img/.iso)、GZip(.gz)、GZipped Tar(.tgz/.tar.gz)、Microsoft Cabinet(.cab)、RAR(.rar)、Red Hat(.rpm)、Tar(.tar)、Windows Imaging(.wim/.swm)、Xz(.xz)、Zip(.zip/.zipx/.jar/.ear/.war/.bcpkg)。
- 设置 > 压缩文件类型 页：为每种格式配置关联掩码（留空即删除支持）；添加 Total Commander"打包器"插件扩展格式（如 ISO、MSI 插件）。
- 行为：默认按"打开后作为文件夹"处理；压缩包内文件支持全部常规操作（比较内容、复制、重命名等，读写能力因格式而异；CHM/RAR 等只读来源禁用编辑）；可将复制目标设为压缩包（不存在则创建）。

## 4.11 快照（Snapshots）

FR-SNAP-001 快照概念
- 工具 > 保存快照：保存指定文件夹及全部子文件夹的压缩只读列表（文件名、时间戳、大小、属性），可另存 CRC、exe 版本、展开的压缩包内容。
- .bcss 可像任何基文件夹一样加载比较；二进制与基于规则的内容比较不适用（文件内容不存在）；快照含 CRC 时可用 CRC 比较检测内容变化（含数据损坏检测）。
- 快照记住生成它的基文件夹名：命令行/拖放加载快照时自动与原文件夹比较。

FR-SNAP-002 保存选项
- save-crc（CRC32）、save-version（exe/dll 版本）、expand-archives（压缩包内容展开列表）、include-empty（空文件夹/全被过滤的文件夹）、follow-symlinks（符号链接目标）、no-filters（忽略会话过滤器存储所有文件，否则用文件夹会话的文件过滤器）；从当前文件夹视图可直接选左/右基文件夹。

## 4.12 文件操作对话框通用行为（OP）

FR-OP-001 选择与文件夹语义（复制/移动/删除/交换/合并通用）
- 选中文件夹 → 仅处理其过滤后内容；选中已打开文件夹且其子项也被选中 → 忽略文件夹仅处理子项。

FR-OP-002 确认体系（程序选项 > 文件操作）

FR-OP-003 后台操作
- 文件操作以后台任务执行并带暂停能力（官网特性：Background operations with pause）；带进度显示。

## 4.13 撤销 / 重做（UNDO）

FR-UNDO-001
- 文本比较/合并/十六进制/文本编辑视图内编辑支持多级撤销（撤销上一个操作）与重做。
- 边界："重新比较文件"保留编辑但不保留可撤销性；文件操作（复制/移动/删除等）不属于编辑撤销范围（删除可走回收站兜底）。

## 4.14 查找 / 替换（FIND）

FR-FIND-001 文本查找替换

FR-FIND-002 查找文件名（文件夹视图）

FR-FIND-004 增量搜索

## 4.15 字符编码（ENC）

FR-ENC-001
- 完整 Unicode 与 MBCS 支持；多数文本文件编码自动检测（ChsDet 等检测库）。
- 文件格式可指定代码页；会话可按文件覆盖编码（会话设置 > 格式 > 编码覆盖）。

## 4.16 大文件处理策略（BIG）

FR-BIG-001
- 分级比较策略：快速测试（时间戳/大小）先行，内容比较可配"快速测试相同则跳过"；CRC 惰性计算；zip 预计算 CRC 直接复用。
- 十六进制比较提供"快速"对齐（适合大文件）；"完全"对齐用复杂算法。
- 标准对齐算法分块渐进显示；Myers 一次性比较（大文件慢、完成前不显示）。
- 每行字符限制（文件格式）对超长行断行显示，保存时还原。
- 后台扫描子文件夹、后台文件操作（可暂停）避免阻塞 UI。
- 快照机制：超大目录树（整盘）可用极小 .bcss 记录状态供日后比较。

# 5. 非功能需求（NFR）

NFR-PERF-001 性能
- 响应式多线程界面：文件夹后台扫描、渐进式文本对齐显示（标准对齐在完成前可显示各部分）、后台文件操作可暂停。
- 大目录：快照机制（整盘级树状态极小体积）；显示过滤器与展开范围控制内存。
- 大文件：十六进制"快速"对齐；文件格式"每行字符限制"；Myers 对齐为可选（性能提示明确：大文件一次性比较慢）。
- CRC：惰性按需计算；能复用预计算值（zip）。
- macOS 性能改进与 Apple Silicon 原生（BC5）。

NFR-PERF-002 正确性边界
- CRC 相同 ≠ 内容相同（概率性）；文档明确"很可能匹配"。
- 对齐算法可能次优 → 提供手动对齐兜底。

NFR-PLAT-001 跨平台
- Windows / macOS / Linux 全功能对齐（平台差异项以图标标注：注册表比较仅 Windows 有实时注册表对象；DOS 属性、8.3 别名、NTFS ACL 为 Windows 特性；attrib/exclude-protected 等脚本命令非 Win 平台不支持）。
- 开关前缀差异（`/` vs `-`）；可执行文件差异（BComp.exe/BComp.com vs bcomp）。

NFR-LIC-001 许可
- Standard / Pro 双版本单安装；密钥解锁；试用全功能；按用户许可（多机安装）；升级政策。

NFR-USE-001 可用性
- 全键盘可达 + 快捷键全自定义；颜色主题（浅/深/跟随系统）+ 完全可定制颜色字体；图例窗口；高 DPI/Retina/每监视器缩放；上下文相关帮助；帮助提示时延可调。
- 多语言 UI（英/德/法/日/中）。

NFR-SEC-001 安全
- 管理策略三开关；SFTP/FTPS 加密传输；密码可策略性禁存；OAuth 云存储授权。

NFR-ROB-001 健壮性
- 设置自动备份（.bak）；加载失败错误对话框；脚本 stop-on-error 与确认策略；退出时未保存命名会话参数提示；操作确认体系；便携式安装。

# 6. 优先级划分（P0 / P1 / P2）

> 定义：P0 = MVP 必须（缺失则产品不可用）；P1 = 重要（正式版应有，缺失显著削弱可用性）；P2 = 增强 / Pro 专属能力（差异化与高级场景）。理由栏说明划分依据。

## 6.1 会话类型优先级

| 会话类型 | 优先级 | 理由 |
| --- | --- | --- |
| 文本比较 | P0 | 产品最核心场景：代码/配置 diff、行内差异、编辑、忽略规则是品牌立身之本 |
| 文件夹比较 | P0 | 与文本比较并列的核心：目录树对比、比较基准、过滤、复制/删除等操作构成日常工作流主干 |
| 文本合并（三向） | P1 | Pro 旗舰功能、VCS 冲突解决刚需；但依赖文本比较先成熟（算法与重要性模型复用） |
| 文件夹同步 | P1 | 独立高频场景（备份/镜像/更新）；状态机较简单（5 种预设），复用文件夹比较基座 |
| 表格比较 | P1 | CSV/Excel 数据比较是差异化能力；键列 + 容差模型独立开发量中等 |
| 十六进制比较 | P1 | 二进制 diff 的通用兜底视图，也是"无匹配格式"时的退路之一；算法相对简单 |
| 文本编辑视图 | P1 | 作为"打开方式"与"在文件中查找"载体，成本低（单窗格复用编辑器） |
| 文本补丁视图 | P1 | diff/patch 文件查看是开发者刚需；解析 unified/context/normal 格式工作量可控 |
| 文件夹合并（三向） | P1 | 与文本合并配套的 Pro 能力；合并状态机（无需操作/自动合并/需手动）可基于文件夹比较扩展 |
| 图片比较 | P2 | 专业场景（设计/像素校验）；三种模式 + 几何对齐独立渲染管线，成本高、受众窄 |
| 版本比较 | P2 | 窄场景（exe/dll 版本资源）；依赖 PE 资源解析 |
| 媒体比较（FLAC/MP3/MP4） | P2 | 窄场景；标签解析 + 播放集成 |
| 注册表比较 | P2 | Pro 专属且仅 Windows 有实时对象；跨平台复刻价值低 |
| 剪贴板比较 | P2 | 托盘常驻辅助工具；与主程序耦合低，可后置 |

## 6.2 功能域优先级

| 功能域 | 优先级 | 覆盖内容与理由 |
| --- | --- | --- |
| FR-SES 会话管理（保存/自动保存/默认设置/作用域） | P0 | BC 的"记忆"是核心差异化；无会话则每次重复配置 |

| FR-DIR 010-012 比较基准 | P0 | 快速测试全集 + 二进制/CRC 内容比较；基于规则比较可 P1（依赖文件格式） |
| FR-DIR 030-036 过滤体系 | P0 | 名称过滤器 + 显示过滤器 + 抑制过滤器；其他过滤器可 P1 |
| FR-DIR 060-068 文件操作 | P0 | 复制/移动/删除/重命名/属性/时间戳是"协调差异"的落点 |
